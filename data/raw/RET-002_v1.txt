Return Process SOP

Step 1: Agent verifies the order ID and delivery date. Step 2: Agent checks the item is eligible under the current Return Policy. Step 3: Agent raises a return ticket and schedules pickup. Step 4: Warehouse inspects the item within 2 working days. Step 5: Refund is initiated if inspection passes.
